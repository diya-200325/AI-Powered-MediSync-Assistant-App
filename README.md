# Sympto: AI-Powered MediSync Assistant

## Overview
Sympto is an AI-powered healthcare assistant that helps users analyze symptoms, receive basic health recommendations, and manage medication reminders through an easy-to-use mobile application.

## Key Features
- AI-based symptom analysis
- Personalized health recommendations
- Medication reminder system
- User-friendly Android application
- Secure health data management

## Technologies Used
- Java
- Android Studio
- Firebase
- AI-based symptom prediction
- REST APIs
