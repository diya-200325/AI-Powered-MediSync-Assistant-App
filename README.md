## 📖 Overview

**Sympto** is a smart healthcare assistant designed to make basic healthcare guidance more accessible. The application allows users to enter their symptoms, receive AI-powered health suggestions, set medication reminders, and securely manage their health information.

The app combines **Artificial Intelligence**, **Firebase**, and **Android development** to provide an intelligent and user-friendly healthcare experience.

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/yourusername/Sympto.git
```

### Navigate to the project

```bash
cd Sympto
```

### Open in Android Studio

- Open Android Studio
- Select **Open Existing Project**
- Choose the cloned project folder
- Sync Gradle
- Run the application on an emulator or Android device
